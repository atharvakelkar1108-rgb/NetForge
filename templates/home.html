Features

Three jobs, one tool

Everything runs on one topology you draw: the same network is designed, checked and simulated.

Design

Visual topology builder

Drag routers, switches and hosts onto a canvas, connect them, and configure IPs, masks, VLANs, gateways and static routes.

Validate

24 configuration rules

Duplicate IPs, subnet and VLAN mismatches, bad gateways, loops. Faulty devices are circled in red with a suggested fix and a health score.

Simulate

Hop-by-hop packets

Ping and traceroute with ARP, TTL and routing lookups. The reply must return too, so one-way misconfigurations show up as timeouts.

Routing

OSPF vs RIP

OSPF picks the lowest link cost, RIP the fewest hops. Compare both on the same packet and see the paths differ.

Resilience

Failure and reroute

Take any link down and watch traffic find another path, or fail when none is left.

Security

Firewall ACLs and VLANs

Block specific hosts on a router and see exactly which rule stopped the packet. VLANs isolate hosts across a switch.

Insight

Reachability matrix

Every host pings every other host in one click, so a single broken rule shows up as a red cell.

Export

Cisco-style configs

Generate ready-to-read configuration for each device, including access lists, then save projects to your account.

How it works

From drawing to proof in three steps

01

Design

Place devices, draw links and type in the addressing. Or load one of the example labs.

02

Validate

One click checks the whole network against the rules and shows what is wrong and how to fix it.

03

Simulate

Ping or trace between any two devices, break a link, add a firewall rule, and watch what changes.
